# RoastMemo — 焙煎プロファイル記録計

RoastMemo は、自家焙煎コーヒーの **焙煎プロファイル**（時間ごとの豆温度の推移＝焙煎カーブ）を
記録し、ロット同士を重ねて見比べるための Web アプリ／PWA です。ストリップチャート式の
サーモグラフ（記録計）を模した盤面に、あなたの焙煎が一枚のカーブとして残ります。

焙煎の再現性は「前回と同じように進んだか」を確かめられるかどうかで決まります。RoastMemo は、
勘や記憶に頼っていた焙煎の進み方を目に見えるカーブとして残し、次の一焙りに活かすための道具です。
入力した焙煎ログ（豆名・焙煎カーブ・メモ・タグ）はお使いの端末内（ブラウザの IndexedDB）にのみ保存され、外部サーバーへ送信・アップロードされません。アカウント登録も不要です。

## こんな人に

- ハンドロースト／小型焙煎機で自家焙煎していて、毎回の進み方を記録・比較したい
- 「前回の方が良かった」を感覚ではなくカーブで振り返りたい
- 投入量・排出量から重量減少率（歩留まり）を毎回きちんと押さえたい
- 豆ごと・焙煎度ごとに所見やフレーバーを蓄積して検索したい

## できること

- **焙煎カーブの記録** — 経過時間（分:秒）と豆温度（℃）の計測点を足していくと、盤面に
  サーマルグラデーション（琥珀→残り火色）のカーブが描かれます。
- **イベントマーカー** — 乾燥終わり・1ハゼ・2ハゼ・ドロップを、その時刻に旗として立てられます。
- **重量減少率の自動計算** — 投入量と排出量を入れると減量率（%）を即座に表示し、焙煎度合いの
  目安を色スウォッチで示します。
- **複数ロットの重ね比較** — 保存した焙煎を選ぶと、そのカーブを半透明のゴースト線で盤面に重ねられます。
- **カッピング・所見メモ** — 焙煎直後の香りや狙い、気づきを自由記述で残せます。
- **フレーバータグ** — ベリー／チョコ／柑橘のように、自分の言葉でタグを付け、タグで絞り込めます。
- **全文検索** — 豆名・日付・メモ・タグ・イベントを横断してインクリメンタルに検索できます。
- **バックアップ（JSON 書き出し・取り込み）** — 端末内のデータを JSON で書き出し、別の端末で
  取り込んで移行できます。

## 使い方

1. 上部の入力レールで「時間（分:秒）」と「温度（℃）」を入れ、**点を記録**を押していきます。
2. ハゼなどのタイミングでイベントボタンを押すと、その時刻に旗が立ちます。
3. 豆の名前・日付・投入量・排出量を入れ、カッピングメモとフレーバータグを付けます。
4. **この焙煎を保存**で端末内に保存すると、下の一覧にカーブ付きで並びます。
5. 一覧で複数の焙煎の**重ねる**を押すと、盤面でカーブを重ねて比較できます。
6. 検索やタグで過去の焙煎を絞り込めます。

## 制限事項

- 温度を自動取得する機能はありません。豆温度は温度計の読みを手入力します。
- 焙煎ログは端末内（ブラウザの保存領域）にのみ保存されます。ブラウザのデータを消去すると失われるため、
  大切な記録は JSON バックアップを取ってください。端末間の共有・同期はバックアップの取り込みで行います。

## 開発

Next.js（App Router）。`out/` への static export で配信するためサーバーランタイムは不要です。

```bash
./setup.sh                 # 依存の導入
pnpm dev                   # http://localhost:3000（ホットリロード）
pnpm build                 # next build → out/ に静的 HTML/CSS/JS を生成
./run.sh serve             # out/ をビルドしてローカル配信
pnpm test                  # node --test（ロジックの単体テスト）
pnpm lint                  # next lint
pnpm typecheck             # tsc --noEmit
```

`out/` がそのまま配信物です（`next start` は使いません）。GitHub Pages のプロジェクトページ配信では
`NEXT_PUBLIC_BASE_PATH=/roastmemo pnpm build` のように basePath を注入してビルドします。
